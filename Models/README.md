# Native DReAMy resources

Run `python3 scripts/fetch_dreamy_model.py` from a fresh checkout. The generated 200+ MB Core ML package is a verified GitHub release asset and is excluded from Git history. The vocabulary and synthetic native test fixtures are tracked here. No dreams or recordings belong in this folder.

The app compiles and bundles this package for offline inference. Runtime model downloads and external AI servers are not used. See `docs/DREAMY_INTEGRATION.md` for provenance, licensing and conversion instructions.
